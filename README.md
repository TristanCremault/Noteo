# Noteo

Un seul dépôt pour tout :

- `site/`  : page d'accueil (téléchargements)
- `phone/` : version téléphone (appli web + emballage Android)
- `pc/`    : version ordinateur (Electron + installateur Windows)
- `.github/workflows/` : `pages.yml` (site + appli web), `apk.yml` (Android), `windows.yml` (Windows)

Adresses (dépôt nommé `Noteo`) : page d'accueil `https://<pseudo>.github.io/Noteo/`, appli web `.../Noteo/app/`.
Téléchargements : onglet Releases (`apk-latest`, `pc-latest`).
